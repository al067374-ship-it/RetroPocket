# RetroPocket — Guía de emulación en Android

Sitio informativo estático, responsive y en español sobre emulación retro en Android.

## Contenido
- Introducción a la emulación.
- Fichas de PPSSPP, DuckStation, Flycast, RetroArch y melonDS.
- Guía de configuración inicial.
- Flujo de aplicación de parches con UniPatcher.
- Introducción a RetroAchievements.
- Recursos oficiales y preguntas frecuentes.

## Ejecutar localmente
Abre `index.html` en un navegador. No requiere Node.js, compilación ni dependencias.

## Publicar gratis con GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `retropocket`.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raíz del repositorio.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda los cambios.
6. Espera a que GitHub Pages publique el sitio. La URL aparecerá en esa misma sección.

## Publicar con Vercel
Importa el repositorio desde Vercel y despliega como proyecto estático. No se necesita comando de build.

## Nota legal
